# 从 C 内存模型到嵌入式 C

这是一套以实验为主的完整 C 学习资料。目标不是背完语法，而是达到：

- 能解释变量、指针、数组和动态内存的真实行为；
- 能独立组织多文件 C 工程并调试；
- 能实现常见数据结构、状态机和回调；
- 能读懂寄存器、位操作、`volatile` 和嵌入式驱动接口；
- 能开始 ESP32、STM32 或 FreeRTOS 项目。

它覆盖转嵌入式所需的 C 主干，但不等于完整复制 ISO C 标准。高级编译器实现、复杂宏元编程、内核和硬件驱动属于后续专题。

## 学习规则

每一课都执行以下动作：

1. 运行前预测变量值、地址关系和输出。
2. 给每个对象画内存格，指针画箭头。
3. 编译运行，对比预测。
4. 完成源码末尾的 `TRY`。
5. 在 [WORKBOOK.md](WORKBOOK.md) 写下自己的解释。

不要一天刷十课。推荐每天一课加一个小练习，每周留一天复习和重写。

资料使用顺序：

1. 在 [GUIDE.md](GUIDE.md) 阅读对应概念。
2. 运行 `lessons/` 中对应实验并完成 `TRY`。
3. 在 [WORKBOOK.md](WORKBOOK.md) 回答问题。
4. 对照 [ANSWERS.md](ANSWERS.md) 的逐课答案和参考代码。
5. 完成 [EXERCISES.md](EXERCISES.md)，卡住后再看 [EXERCISE_HINTS.md](EXERCISE_HINTS.md)。

完成 24 课后使用扩展资料：

- [EMBEDDED_GUIDE.md](EMBEDDED_GUIDE.md)：25～46 课原理讲义
- [EMBEDDED_WORKBOOK.md](EMBEDDED_WORKBOOK.md)：STM32 对接自测题
- [EMBEDDED_ANSWERS.md](EMBEDDED_ANSWERS.md)：25～46 课 `TRY` 参考答案
