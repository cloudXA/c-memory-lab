# 从 C 内存模型到嵌入式 C

这是一套以实验为主的完整 C 学习资料。目标不是背完语法，而是达到：

- 能解释变量、指针、数组和动态内存的真实行为；
- 能独立组织多文件 C 工程并调试；
- 能实现常见数据结构、状态机和回调；
- 能读懂寄存器、位操作、`volatile` 和嵌入式驱动接口；
- 能开始 ESP32、STM32 或 FreeRTOS 项目。

它覆盖转嵌入式所需的 C 主干，但不等于完整复制 ISO C 标准。高级编译器实现、复杂宏元编程、内核和硬件驱动属于后续专题。

## 学习规则

每一课都执行以下动作：

1. 运行前预测变量值、地址关系和输出。
2. 给每个对象画内存格，指针画箭头。
3. 编译运行，对比预测。
4. 完成源码末尾的 `TRY`。
5. 在 [WORKBOOK.md](WORKBOOK.md) 写下自己的解释。

不要一天刷十课。推荐每天一课加一个小练习，每周留一天复习和重写。

## 课程地图

### A. 内存模型

| 课 | 主题 | 核心问题 |
|---|---|---|
| 01 | 字节和变量 | 类型如何解释字节？ |
| 02 | 一级指针 | `p`、`&p`、`*p` 分别是什么？ |
| 03 | 数组 | 为什么 `a[i] == *(a+i)`？ |
| 04 | 栈和传参 | 值传递为什么改不了调用者变量？ |
| 05 | 堆 | `malloc/free` 管理谁的生命周期？ |
| 06 | 结构体布局 | 对齐和填充从哪里来？ |
| 07 | 二级指针 | 如何修改调用者的指针？ |

### B. C 语言主体

| 课 | 主题 | 核心问题 |
|---|---|---|
| 08 | 表达式和控制流 | 条件、循环如何组织逻辑？ |
| 09 | 整数类型与转换 | 有符号、无符号混用为何危险？ |
| 10 | 函数、作用域、存储期 | `static` 到底改变什么？ |
| 11 | 字符串 | 字符数组与字符串有什么区别？ |
| 12 | `const` 指针 | 谁不能被修改？ |
| 13 | 枚举、联合体 | 如何表达状态和共享存储？ |
| 14 | 位运算 | 如何读写某一位？ |
| 15 | 函数指针和回调 | 如何把行为作为参数传递？ |

### C. 工程化与可靠性

| 课 | 主题 | 核心问题 |
|---|---|---|
| 16 | 预处理器 | 宏和条件编译何时使用？ |
| 17 | 声明、定义、链接 | `.h`、`.c`、`extern` 如何配合？ |
| 18 | 错误处理 | C 没有异常时如何传递失败？ |
| 19 | 所有权 | 谁负责释放资源？ |
