# 实验记录册

不要追求一次答对。先写预测，再写实际结果，最后解释差异。

## 第 1 课：字节与变量

- `sizeof(char)`、`sizeof(int)`、`sizeof(double)` 分别是多少？
- `int` 的多个字节在你的 Mac 上按什么顺序排列？
- 内存本身是否知道一组字节是整数还是浮点数？

## 第 2 课：一级指针

- `p`、`&p`、`*p` 各自是什么值？
- 执行 `*p = 99` 修改的是 `p` 还是 `x`？
- 为什么 `int *p` 中的 `int` 很重要？

## 第 3 课：数组

- 相邻两个 `int` 元素的地址相差多少？为什么？
- `a`、`&a[0]` 数值是否相同？类型是否完全相同？
- 用一句话解释 `a[2] == *(a + 2)`。

## 第 4 课：栈与函数

- `change_value(x)` 为什么不能修改 `x`？
- `change_through_pointer(&x)` 为什么可以？
- 函数返回后，它的局部变量发生了什么？

## 第 5 课：堆

- `p` 和 `p` 指向的数组分别通常位于哪里？
- `free(p)` 释放的是指针变量，还是它指向的内存？
- `free` 后为什么给 `p = NULL` 仍不能让其他别名指针安全？

## 第 6 课：结构体

- `sizeof(struct Sample)` 是否等于字段大小之和？
- 每个字段相对结构体起始地址的偏移是多少？
- 调换字段顺序后结构体大小是否改变？

## 第 7 课：二级指针

- `pp` 是什么变量？它保存谁的地址？
- `*pp` 和 `**pp` 分别得到什么？
- 为什么 `allocate_one(&p)` 需要传 `&p` 而不是 `p`？

## 第 8～11 课：语言基础

- `for` 循环的三个表达式分别承担什么责任？
- 为什么 `-1 < 1U` 的结果可能违反直觉？
- 局部 `static` 的作用域和生命周期分别是什么？
- `sizeof(char_array)` 与 `strlen(char_array)` 为什么不同？
- 字符串字面量为什么用 `const char *` 接收？

## 第 12～15 课：类型和抽象

- `const int *p` 与 `int *const p` 分别限制谁？
- 枚举相对于裸整数有什么优势？
- 联合体成员为什么拥有相同起始地址？
- 写出置位、清零、翻转和测试第 n 位的表达式。
- 回调函数中的 `void *context` 解决了什么问题？

## 第 16～19 课：工程化

- 宏为什么可能重复执行参数中的副作用？
- 声明和定义有什么区别？
- 文件作用域 `static` 如何隐藏实现？
- 为什么输出参数只能在返回成功后使用？
- 包含动态指针的结构体直接赋值会产生什么风险？

## 第 20～21 课：数据流和状态

- 环形缓冲区如何判断空和满？

## 第 22～24 课：嵌入式桥梁

- 为什么协议解析不能依赖本机字节序？
