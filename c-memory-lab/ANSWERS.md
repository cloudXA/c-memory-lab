# 参考答案

先完成实验，再阅读本文件。

## 核心答案

1. 变量是有类型、有大小、有生命周期的一块对象存储；地址是它在一次运行中的位置。
2. `p` 是指针变量，保存目标对象的地址；`&p` 是指针变量自己的地址；`*p` 是通过地址访问目标对象。
3. 数组元素连续存放。指针加一按其指向类型的大小移动，所以 `a + 2` 指向第 3 个元素，解引用后就是 `a[2]`。
4. C 参数按值传递。传 `x` 复制整数，传 `&x` 也复制，但复制的是能找到 `x` 的地址。
5. `malloc` 创建指定字节数的动态存储并返回首地址。`free` 结束该动态存储的生命周期，不会自动修改任何保存旧地址的指针。
6. 结构体可能为满足字段对齐要求而插入填充字节；字段顺序可能影响总大小。
7. `pp` 是一个普通变量名，类型为 `int **`。它保存 `int *` 对象的地址。通过 `*pp` 可以修改那个 `int *` 对象本身。

## 最终口述题

```c
int *p = malloc(10 * sizeof(*p));
```

- 声明一个名为 `p`、类型为 `int *` 的指针对象。
- `*p` 这个表达式的类型是 `int`。
- 普通情况下 `sizeof` 不执行 `*p`，只取得其类型大小。
- 请求一块至少能容纳 10 个 `int` 的连续动态存储。
- `malloc` 返回该存储首地址；失败时返回空指针。
- 返回的地址用于初始化 `p`。
- `p + 1` 前进一个 `int` 的大小。
- 成功后可通过 `p[0]` 到 `p[9]` 访问对象；读取尚未初始化的元素仍是错误行为。
- `free(p)` 后动态存储失效，`p` 自身仍存在但保存的是失效地址，通常应随后令 `p = NULL`。
