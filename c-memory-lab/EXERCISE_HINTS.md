# 分层练习提示

至少独立尝试 30 分钟后再看。本文件给拆解方法，不给完整项目成品。

1. `swap`：保存 `*a` 的旧值，再依次赋值；先检查空指针。
2. `array_max`：先处理空数组，用首元素初始化最大值，成功后写入 `out`。
3. `string_length`：索引从 0 开始，直到遇见 `\0`。
4. `string_copy`：先确认目标容量能容纳字符和结尾 `\0`。
5. 动态数组：考虑数量乘元素大小的溢出；所有提前返回路径都要清理。
6. 大端编码：高 8 位先写；解码时先转无符号宽类型再移位。
7. 位字段：先清除掩码区域，再写入裁剪后的新字段。
8. 权限位：每个权限占互不重叠的一位，复用第 14 课操作。
9. 数组参数：形参中的 `int a[]` 会调整为 `int *a`，容量需额外传入。
10. 动态向量：保存 `data/size/capacity`，用临时指针接收 `realloc`。
11. 环形缓冲区：先写空、满、绕回三个测试。
12. 多文件：公共类型与声明放 `.h`，实现细节与 `static` 函数放 `.c`。
13. 接口文档：逐个说明前置条件、失败结果和资源所有权。
14. 按键消抖：区分稳定态和等待确认态，达到时间阈值才迁移。
15. 初始化超时：事件包含开始、成功、失败和 tick，状态保存截止时间。
16. UART 接口：定义 `write(context, bytes, length)`，业务层只持有接口。
17. 协议解析：帧头同步、验证长度、接收负载、核对校验，错误后重置。

调试题应每题单独建立最小程序。先预测错误，再用 Sanitizer 运行；不要把故意的未定义行为放进正常课程代码。
