# 分层练习题

## 基础题

1. 写 `swap(int *a, int *b)`，画出调用时的指针关系。
2. 写 `array_max(const int *values, size_t count, int *out)`，空数组返回失败。
3. 自己实现 `string_length`，不能调用 `strlen`。
4. 自己实现安全版本 `string_copy`，目标空间不足时返回失败。
5. 动态申请 `count` 个整数，初始化、打印、释放，并处理 `count == 0`。

## 类型与位操作

6. 将一个 `uint16_t` 编码成两个大端字节，再解码回来。
7. 用掩码设置一个寄存器的第 4～6 位，不能影响其他位。
8. 定义权限位：读、写、执行，并实现添加、删除、检查权限。
9. 比较 `sizeof(array)` 和函数参数中的 `sizeof(array_parameter)`。

## 工程题

10. 实现动态整数向量，包含初始化、追加、删除和销毁。
11. 实现固定容量环形缓冲区，不能使用动态内存。
12. 把环形缓冲区拆成头文件、实现文件和测试文件。
13. 为所有公共函数写清参数合法性、返回值和所有权。

## 嵌入式题

14. 实现按键消抖状态机。
15. 实现带超时的设备初始化状态机。
16. 设计 UART 发送接口，业务层不能依赖具体串口编号。
17. 解析项目 2 的串口协议，并为错误校验帧编写测试。

## 调试题

下面每种错误都单独写一个最小程序，并使用编译器警告或 Sanitizer 观察：

- 数组越界；
- use-after-free；
- 内存泄漏；
- 返回局部变量地址；
- 空指针解引用；
- 有符号整数溢出。

危险程序不要合并进正常课程示例，以免误运行。
