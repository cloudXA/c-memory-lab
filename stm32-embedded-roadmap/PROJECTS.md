# 阶段项目

## 项目 1：裸机多功能控制台

功能：

- 按键短按/长按；
- LED 状态显示；
- 定时器实现非阻塞周期任务；
- UART 命令控制；
- 查询系统时钟、运行时间和错误计数。

要求：

- 不在业务循环中使用长 `HAL_Delay`；
- UART 使用环形缓冲区；
- 命令解析有长度限制和错误回复；
- 按键中断只投递事件；
- 业务使用状态机；
- 模块至少拆成 `bsp_led`、`bsp_button`、`console`、`app`。

验收：持续快速输入不会越界；按键抖动不重复触发；未知命令不导致卡死。

## 项目 2：传感器采集终端

功能：

- I2C 或 SPI 读取真实传感器；
- 定时采样；
- ADC + DMA 采样一路模拟量；
- UART 输出结构化数据；
- 参数保存到内部 Flash；
- 看门狗和故障恢复。

要求：

- 传感器驱动与业务层解耦；
- 所有 HAL 调用处理返回值和超时；
- 断开传感器后进入故障状态并有限重试；
- Flash 数据包含版本、长度和校验；
- README 包含时钟计算、接线图和状态机。

验收：运行至少 2 小时；传感器断开并重新接入后可恢复；错误不会阻塞其他功能。

## 项目 3：FreeRTOS 设备节点

在项目 2 基础上改造：

```text
采集任务 -> 队列 -> 处理任务 -> 队列 -> UART 通信任务
按键 ISR -> 任务通知 -> 控制任务
```

要求：

- 明确每个外设的唯一所有者；
- ISR 只使用 `FromISR` 接口；
- 不通过裸全局变量传递传感器数据；
- 记录任务栈高水位；
- 故意制造并修复一个竞态；
- 看门狗只在关键任务健康时刷新。

验收：说明任务优先级依据；压力输入下不丢关键命令；无死锁和栈溢出。
