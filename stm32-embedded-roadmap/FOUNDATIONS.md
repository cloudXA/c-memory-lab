# STM32 必备底层原理

## 1. MCU 不是“只有 CPU”

STM32 MCU 通常集成：

```text
Cortex-M CPU 内核
├── 寄存器与指令执行
├── NVIC 中断控制器
├── SysTick
└── 调试组件

芯片资源
├── Flash：保存程序和常量
├── SRAM：运行时变量、栈、堆
├── 时钟与复位 RCC
├── GPIO
├── 定时器
├── UART/I2C/SPI
├── ADC/DMA
└── 看门狗等其他外设
```

CPU 通过地址访问 SRAM，也通过地址访问外设寄存器，这就是存储器映射 I/O。

## 2. 存储器映射与寄存器

寄存器不是普通软件变量，而是芯片内部硬件控制位映射到地址空间后的接口。

概念示例：

```c
volatile uint32_t *reg = (volatile uint32_t *)0x40000000U;
*reg |= UINT32_C(1) << 3U;
```

实际项目优先使用 CMSIS 定义或 HAL，不手写地址。必须理解：

- 寄存器宽度；
- 每个位或字段的含义；
- 只读、只写、读写、写 1 清零等访问规则；
- 保留位不能随意修改；
- `volatile` 保证实际访问，但不保证原子性和线程安全。

## 3. Flash、SRAM、栈和堆

常见布局：

```text
Flash
├── 向量表
├── 程序代码 .text
└── 只读数据 .rodata

SRAM
├── 已初始化全局/静态数据 .data
├── 零初始化数据 .bss
├── 堆（若使用动态分配）
└── 栈（函数调用、局部变量）
```

嵌入式岗位要能解释：

- `.data` 的初值来自 Flash，启动时复制到 SRAM；
- `.bss` 启动时清零；
- 局部自动对象通常在栈中；
- 大数组可能导致栈溢出；
- MCU RAM 小，动态分配要谨慎，不是绝对禁止；
- 链接脚本决定代码和数据放在哪里。

## 4. 从上电到 main

典型流程：

```text
复位
  ↓
CPU 从向量表读取初始栈指针和 Reset_Handler
  ↓
设置时钟或执行芯片基础初始化
  ↓
复制 .data、清零 .bss
  ↓
调用 SystemInit
  ↓
调用 C 运行库初始化
  ↓
进入 main
  ↓
HAL_Init / SystemClock_Config / 外设初始化 / 业务循环
```

你不需要立刻会写启动文件，但要能找到：

- `startup_stm32*.s`
- `system_stm32*.c`
- 链接脚本或 scatter file
- 中断向量表

## 5. Cortex-M3 执行模型

基础寄存器概念：

- `R0-R3`：常用于参数和临时值；
- `R13/SP`：栈指针；
- `R14/LR`：链接寄存器，保存返回相关信息；
- `R15/PC`：程序计数器；
- `xPSR`：状态信息。

函数调用通常通过寄存器传参，必要时使用栈。优化级别会改变变量是否真实位于内存，所以调试时不要把源码变量布局想成绝对不变。

## 6. 时钟树

时钟决定 CPU 和外设“每秒运行多少拍”。常见节点：

```text
HSI/HSE
   ↓
  PLL
   ↓
SYSCLK
   ↓
 AHB 分频 → HCLK/CPU
   ├── APB1 分频 → PCLK1 → 低速外设
   └── APB2 分频 → PCLK2 → 高速外设
```

学习时必须手算：

```text
SYSCLK = 输入时钟 × PLL 倍频/预分频
HCLK   = SYSCLK / AHB 分频
PCLKx  = HCLK / APBx 分频
```

注意 STM32F1 的某些定时器：当 APB 预分频不为 1 时，定时器输入时钟可能是对应 PCLK 的 2 倍。必须查参考手册和 CubeMX 时钟树。

## 7. 中断完整路径

以 GPIO 外部中断为例：

```text
引脚电平变化
  ↓
EXTI 检测边沿并置 pending 标志
  ↓
NVIC 判断使能和优先级
  ↓
CPU 保存必要现场并跳转 IRQHandler
  ↓
HAL IRQ Handler 读取/清除标志
  ↓
调用用户回调
  ↓
异常返回，恢复被打断代码
```

ISR 原则：

- 快进快出；
- 不调用无限等待接口；
- 不在中断中执行长日志；
- 与主循环/任务共享数据时考虑原子性和同步；
- 清楚标志由谁负责，避免重复进入。

## 8. HAL、LL、CMSIS 和寄存器

| 层级 | 特点 | 学习要求 |
|---|---|---|
| HAL | 易用、可移植、抽象较高 | 能正确调用并理解阻塞/中断/DMA模式 |
| LL | 更接近寄存器，开销较低 | 进阶时学习 |
| CMSIS | Cortex-M 与设备定义基础 | 会识别寄存器结构和 NVIC 接口 |
| 直接寄存器 | 控制精确、耦合芯片 | 用于理解和特殊需求，不必所有业务都手写 |

入职标准不是拒绝 HAL，而是能够从 HAL 问题下钻到寄存器和手册。

## 9. 数据手册与参考手册

- **Datasheet 数据手册**：引脚、电气参数、封装、容量、工作条件。
- **Reference Manual 参考手册**：外设原理、寄存器、时序和工作模式。
- **Programming Manual**：Cortex-M 内核、指令和异常模型。
- **Errata 勘误表**：芯片已知硬件问题和规避方案。
- **原理图**：开发板外部连接。

遇到“这个引脚能不能用、最大电流多少”看数据手册；遇到“定时器寄存器怎么工作”看参考手册。
