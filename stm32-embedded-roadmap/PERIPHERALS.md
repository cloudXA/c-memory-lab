# 外设原理、实验与排错

## GPIO

原理：GPIO 将芯片引脚连接到数字输入/输出逻辑。

必须理解：

- 输入浮空、上拉、下拉；
- 推挽输出可主动输出高低电平；
- 开漏只能主动拉低，输出高通常依赖外部上拉；
- GPIO 速度是输出边沿驱动能力，不是代码执行速度；
- 输入/输出电压、电流和 5 V 容忍必须查数据手册。

实验升级：

1. LED 输出；
2. 按键轮询；
3. 软件消抖；
4. EXTI 中断；
5. 中断只记录事件，主循环处理业务。

常见故障：未开端口时钟、引脚复用冲突、有效电平相反、没有共地、输入悬空、忘记清中断标志。

## 时钟

原理：CPU、总线和外设都依赖时钟。外设时钟未使能时，即使写寄存器也可能没有效果。

实验升级：

1. 使用 HSI 运行；
2. 切换 HSE + PLL；
3. 输出 MCO 或用定时器/串口现象验证频率；
4. 手算 HCLK、PCLK 和定时器时钟。

常见故障：板上晶振与配置不符、Flash 等待周期不正确、APB 超频、定时器倍频规则漏算、串口波特率随时钟错误。

## EXTI 与 NVIC

原理：EXTI 检测外部/内部事件，NVIC 管理 Cortex-M 中断使能、挂起和优先级。

必须理解：多个 EXTI 线可能共享 IRQHandler；回调参数通常用于识别引脚；机械按键抖动会造成多次中断。

常见故障：边沿选反、pending 未清、优先级配置不当、中断中调用阻塞函数。

## 通用定时器

核心公式：

```text
计数频率 = TIM 输入时钟 / (PSC + 1)
更新频率 = 计数频率 / (ARR + 1)
更新周期 = 1 / 更新频率
```

PWM 边沿对齐常见关系：

```text
PWM 频率 = TIM 输入时钟 / ((PSC + 1) × (ARR + 1))
占空比约等于 CCR / (ARR + 1)
```

实验升级：周期中断、PWM、输入捕获、编码器接口。

常见故障：忘记 `+1`、定时器时钟算错、只初始化未启动、通道/引脚复用错误、中断标志未处理。

## UART/USART

一帧常见格式：起始位 + 数据位 + 可选校验位 + 停止位。双方必须匹配波特率和帧格式。

三种模式：

- 阻塞：适合最小验证；
- 中断：适合少量异步数据；
- DMA + 空闲线：适合可变长或持续数据流。

工作中必须处理：

- 接收缓冲区边界；
- 半包、粘包和噪声；
- 超时和校验；
- 回调重新启动接收；
- ISR 与主循环/任务之间的数据交接。

常见故障：TX/RX 没交叉、未共地、电平不兼容、波特率时钟错误、只调用一次中断接收、`printf` 阻塞。

## ADC

理想量化关系：

```text
数字值约等于 Vin / Vref × (2^N - 1)
Vin 约等于 数字值 / (2^N - 1) × Vref
```

实际还受参考电压、源阻抗、采样时间、噪声、校准和芯片误差影响。

实验升级：单次采样、连续采样、DMA 多点采样、均值/中值滤波。

常见故障：采样时间太短、输入超量程、模拟引脚配置错误、DMA 数据宽度错误、把整数除法当浮点计算。

## DMA

DMA 是独立搬运单元，不是“自动多线程”。配置要素：源地址、目标地址、方向、宽度、长度、地址递增、普通/循环模式、优先级。

关键约束：

- 缓冲区在传输完成前必须有效；
- DMA 正在使用时不要无同步地修改缓冲区；
- 处理半完成/完成/错误事件；
- 关注长度单位是字节、半字还是字。

常见故障：DMA 时钟未开、请求映射错误、数据宽度不匹配、栈上临时缓冲区提前失效。

## I2C

线路：SCL、SDA，通常开漏并需要上拉。协议包含 START、地址、读写位、ACK/NACK、数据和 STOP。

注意 7 位地址与 HAL 参数可能采用不同表示方式，必须阅读对应 HAL API 文档，不能盲目左移或重复左移。

实验升级：扫描地址、读取传感器 ID、读取数据、超时恢复。

常见故障：没有上拉、地址格式错误、SDA 被拉低总线锁死、时序过快、设备未上电、读写寄存器顺序错误。

## SPI

线路：SCK、MOSI、MISO、NSS。主机产生时钟，模式由 CPOL/CPHA 决定。

必须理解：SPI 没有统一高层协议；寄存器地址、读写位和帧格式由具体器件规定。没有 ACK，通信成功需要由业务数据确认。

常见故障：模式错误、位序错误、NSS 时序错误、MISO/MOSI 接反、双方数据宽度不同。

## 看门狗

看门狗在软件未按期刷新时复位系统。正确设计：

- 只有关键任务全部健康才喂狗；
- 记录复位原因；
- 能复现死锁、死循环和外设卡死场景；
- 不要在独立高优先级任务里无条件喂狗。

## 内部 Flash

Flash 通常需要先擦除再写入，擦除粒度大于单个变量，写入次数有限。参数保存应考虑：

- 魔数、版本、长度和 CRC；
- 双备份或日志式更新；
- 掉电发生在擦除/写入中间；
- 不要每次主循环都写 Flash。

## 低功耗

理解 Sleep、Stop、Standby 的唤醒代价和保留状态。进入低功耗前要处理外设、时钟和唤醒源；唤醒后可能需要恢复系统时钟。

## CAN/USB 等选修

根据岗位选择：汽车/工业优先 CAN，消费设备可能需要 USB。先打牢 GPIO、时钟、定时器、UART、DMA，再进入复杂协议。
