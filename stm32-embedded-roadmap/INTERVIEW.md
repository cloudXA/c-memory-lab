# 入职与面试清单

## C 必答

- `sizeof(p)` 与 `sizeof(*p)`；
- 数组与指针的区别；
- 栈、堆、静态存储和生命周期；
- 野指针、悬空指针、内存泄漏；
- `const`、`static`、`volatile`；
- 结构体对齐；
- 位运算和寄存器掩码；
- 函数指针和回调；
- 大小端和协议解析；
- 中断共享变量为什么不能只靠 `volatile`。

## STM32 必答

- 从上电复位到 `main`；
- 时钟树和外设时钟门控；
- GPIO 推挽、开漏、上下拉；
- EXTI、NVIC、中断优先级；
- 定时器频率和 PWM 计算；
- UART 轮询、中断、DMA；
- I2C 和 SPI 的区别；
- ADC 分辨率、参考电压和采样时间；
- DMA 配置和缓冲区生命周期；
- 看门狗、Flash、低功耗基础；
- HAL 与寄存器的关系；
- HardFault 如何定位。

## RTOS 必答

- 调度与任务状态；
- 队列、信号量、互斥锁；
- ISR 与任务通信；
- 竞态、死锁、优先级反转；
- 任务栈与堆；
- 周期任务如何减少漂移。

## 面试题回答结构

不要只给定义，按以下顺序回答：

```text
它是什么
为什么需要
硬件/运行机制
常见使用方式
一个真实故障
如何验证和修复
```

例如“UART 丢数据”：

```text
先确认物理接线和波特率；
再确认接收模式和回调是否重启；
检查缓冲区容量、生产消费速度和溢出计数；
用逻辑分析仪确认线上字节；
根据吞吐选择 DMA + 环形缓冲区；
协议层加入长度、校验和重新同步。
```

## 入职第一周应能做到

- 拉取并编译现有工程；
- 找到芯片型号、启动文件、链接配置和 `.ioc`；
- 使用调试器下载、断点和查看调用栈；
- 看懂模块目录和关键任务；
- 根据原理图找到引脚；
- 修改一个小功能并完成回归；
- 不未经确认升级 HAL/固件包或重新生成覆盖代码。

## 判断是否真正掌握

每个模块需要达到：

1. 能复现实验；
2. 能改变参数并预测结果；
3. 能解释寄存器/时序路径；
4. 能故意制造并定位故障；
5. 能脱离视频重建；
6. 能集成到综合项目。
